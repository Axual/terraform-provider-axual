# axual_instance (Resource)

An Instance is a group of one or more Clusters that get the same topics and ACLs. Environments are mapped to an Instance. Use `axual_instance_cluster` to give a Cluster of the Instance a schema registry.

## Usage
- `clusters` lists the Clusters of the Instance (at least one). Topics and ACLs of an environment mapped to the Instance are created on every one of them.
- Removing a Cluster from `clusters` also removes its schema registry configuration. Platform Manager refuses it while a Kafka Connect or Flink cluster is registered on that Instance-Cluster.
- `granular_browse_permission` turns on per-topic browse permissions; manage them with `axual_topic_browse_permissions`.
- `authentication_methods` must be methods the tenant supports. Platform Manager enables `MUTUAL_TLS` when it is not set, and refuses removing a method that is in use.
- An Instance can only be deleted when no environment, Kafka Connect cluster, Flink cluster or connector deployment uses it.
- The `axual_instance` data source looks up an existing Instance.

## Prerequisites
- With `MUTUAL_TLS` enabled and a Cluster with `ssl_auth_mode = "fullChainCertificate"`, `ca_certificates` must hold the CA that signs application certificates.

## Platform Manager version
- Platform Manager 16.0.0 or later.
- Platform Manager refuses a change of `short_name` while the Instance has environments. Some Platform Manager versions delete the schema registry of the Instance-Clusters when `short_name` changes; the next `terraform apply` configures it again from `axual_instance_cluster`.

## Required Roles
- TENANT_ADMIN

## Schema

### Required

- `clusters` (Set of String) IDs of the Clusters in the Instance, at least one. Removing a Cluster deletes its schema registry configuration; Platform Manager refuses it while a Kafka Connect or Flink cluster is registered on it.
- `name` (String) The name of the Instance, unique in the tenant. Must be between 3 and 50 characters: letters, digits, spaces, `.`, `-` and `_`.
- `short_name` (String) The short name of the Instance, unique in the tenant and part of topic names. Lower-case letters and digits, starting with a letter, at most 12 characters. Platform Manager refuses a change while the Instance has environments.

### Optional

- `authentication_methods` (Set of String) How applications may authenticate: `MUTUAL_TLS`, `SCRAM_SHA_256`, `SCRAM_SHA_512`, `OAUTH_BEARER` or `PLAIN`. Each must be enabled for the tenant. Platform Manager enables `MUTUAL_TLS` when it is not set, and refuses removing a method that is in use.
- `ca_certificates` (Set of String) PEM CA certificates that sign application certificates. Required when `MUTUAL_TLS` is enabled and a Cluster has `ssl_auth_mode` `fullChainCertificate`.
- `certificate_reuse_prevention` (String) Whether one certificate may be used by more than one application principal: `NONE`, `INSTANCE` (not twice in the Instance) or `TENANT` (not twice in the tenant). Default `NONE`.
- `connect_enabled` (Boolean) Whether Connector applications can be deployed on the Instance. Default `false`.
- `connect_urls` (List of String) URLs of the Axual Connect REST API, for the legacy Axual Connect. Platform Manager calls each one when `connect_enabled` is `true`.
- `description` (String) A short description of the Instance. Must be at most 200 characters.
- `environment_mapping` (Boolean) Whether environments can be mapped to the Instance. Default `true`.
- `flink_enabled` (Boolean) Whether Flink SQL applications can be deployed on the Instance. Default `false`.
- `granular_browse_permission` (Boolean) Whether topic browsing is allowed per user and group (granular stream browse permissions). Default `false`.
- `properties` (Map of String) Defaults for topics on the Instance, for example `replication.factor`.
- `self_approval` (Boolean) Whether the owner of a topic and an application may approve their own access request. Default `true`.
- `topic_owner_browse_permission` (Boolean) Whether topic owners may always browse their topics. Default `false`.

### Read-Only

- `id` (String) Instance unique identifier

## Example Usage

```hcl
resource "axual_instance" "production" {
  name                       = "Production"
  short_name                 = "prod"
  description                = "Production instance"
  clusters                   = [axual_cluster.production.id]
  ca_certificates            = [file("application-ca.crt")]
  authentication_methods     = ["MUTUAL_TLS", "SCRAM_SHA_512"]
  granular_browse_permission = true
  self_approval              = false
  certificate_reuse_prevention = "INSTANCE"
}
```

For a full example of an Instance with its Cluster and schema registry, see `axual_instance_cluster`.

## Import

Import is supported by ID, or by name (`name:`):

```shell
terraform import axual_instance.<LOCAL NAME> <INSTANCE UID>
terraform import axual_instance.production 9b4b1e3a1e2f4b5f8a1c0d2e3f4a5b6c
terraform import axual_instance.<LOCAL NAME> name:<INSTANCE NAME>
terraform import axual_instance.production 'name:Production'
```

In Terraform 1.12 or later, an `import` block can use `identity` instead of `id`:

```terraform
import {
  to = axual_instance.production
  identity = {
    id = "9b4b1e3a1e2f4b5f8a1c0d2e3f4a5b6c"
  }
}
```
