# axual_topic_browse_permissions (Resource)

With this resource you can configure who can browse a topic's messages in a specified environment.
> Only works if the Environment's Instance has Granular Stream Browse Permissions turned on.
>
> Granular Stream browse permissions are disabled in private environments and in public environments with the authorization issuer set to "auto".

Either users or groups need to be specified — both can't be empty.

Read more: https://docs.axual.io/axual/2026.1/self-service/topic-browse.html#controlling-permissions-to-browse-a-topic

## Required Roles
- Be part of the group owning the Stream. TENANT_ADMIN and STREAM_ADMIN are not enough.
- When the tenant allows only resource managers to change resources, a member must also be a resource manager of that team.

## Schema

### Required

- `topic_config` (String) UID of the Topic configuration. A change does not move the permissions: they stay on the old topic configuration, and the next plan creates them on the new one. To move them, remove the block in one apply and add it again in the next.

### Optional

- `groups` (Set of String) Set of groups who are given Topic Browse permissions.
- `users` (Set of String) Set of users who are given Topic Browse permissions. User can't give Granular Stream Browse Permissions to the user he is logged in as.

## Example Usage

```hcl
resource "axual_topic_browse_permissions" "support_browse_users_and_groups" {
  topic_config = axual_topic_config.support_in_production.id
  users = [data.axual_user.jane.id, data.axual_user.john.id]
  groups = [axual_group.team-awesome.id, axual_group.team-bonanza.id]
}
```

## Import

Topic Browse Permissions can be imported using the topic config ID:

```shell
terraform import axual_topic_browse_permissions.example <topic-config-id>
```

After import, `users` and `groups` are populated from the API based on the current browse permissions for that topic config.

In Terraform 1.12 or later, an `import` block can use `identity` instead of `id`:

```terraform
import {
  to = axual_topic_browse_permissions.example
  identity = {
    topic_config = "b21cf1d63a55436391463cee3f56e393"
  }
}
```
