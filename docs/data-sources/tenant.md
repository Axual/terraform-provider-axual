# axual_tenant (Data Source)

The tenant of the login and its settings. Any user or service account of the tenant can read it. To change the settings, use `axual_tenant_settings`.

## Usage
- `axual_tenant` reads the tenant of the login. It has no arguments.
- Any user or service account of the tenant can read it. No role is needed.
- Use it to name things after the tenant, to check a setting before other resources need it, or to get the ID for an import of `axual_tenant_settings`.
- A setting that Platform Manager has never stored reads as its Platform Manager default: `false`, and `true` for `axual_group_management`.
- `connect_runtime_enabled`, `ksml_runtime_enabled` and `flink_runtime_enabled` are `null` on Platform Manager versions before 17.0.0, which switch Connect and Flink on per Instance.

## Platform Manager version
- Platform Manager 15.0.0 or later.

## Required Roles
- Any role.

## Schema

### Read-Only

- `authentication_methods` (List of String) The login methods that the Instances of the tenant may use, by rank: `MUTUAL_TLS`, `SCRAM_SHA_256`, `SCRAM_SHA_512`, `OAUTH_BEARER` or `PLAIN`.
- `automatic_iam_group_creation` (Boolean) Whether a group of the identity provider becomes an Axual group automatically at login. Needs `iam_group_management = true`; it is `false` while IAM group management is off.
- `axual_group_management` (Boolean) Whether groups and their members are managed in Axual. At least one of `iam_group_management` and `axual_group_management` must be `true`.
- `connect_runtime_enabled` (Boolean) Whether the tenant can use Kafka Connect: Connect clusters and Connector applications. Platform Manager 17.0.0 or later; `null` on older versions, where Connect is switched on per Instance.
- `data_classification_enabled` (Boolean) Whether topics can be given a data classification.
- `data_masking_enabled` (Boolean) Whether data masking can be used. Needed for the `enforceDataMasking` property of `axual_environment`.
- `flink_runtime_enabled` (Boolean) Whether the tenant can use Flink: Flink clusters and Flink SQL applications. Platform Manager 17.0.0 or later; `null` on older versions, where Flink is switched on per Instance.
- `history_retention_days` (Number) How many days the history (audit events) of the tenant is kept. `0` keeps it forever. `null` when the tenant uses the platform value.
- `iam_group_management` (Boolean) Whether groups can be linked to groups of the identity provider (IAM-managed groups).
- `id` (String) The ID of the tenant.
- `ksml_runtime_enabled` (Boolean) Whether the tenant can use KSML: KSML provisioners and KSML applications. Platform Manager 17.0.0 or later; `null` on older versions.
- `name` (String) The name of the tenant.
- `notifications_enabled` (Boolean) Whether users get notifications, for example about access requests.
- `onboarding_completed` (Boolean) Whether the onboarding wizard of the Self-Service UI is finished for the tenant.
- `only_resource_manager_can_update_and_deploy` (Boolean) Whether only the owners of a resource may change and deploy it.
- `schema_roles_enforced` (Boolean) Whether schema roles are enforced on topics.
- `short_name` (String) The short name of the tenant. It is part of topic and group names on Clusters whose pattern has the tenant placeholder.
- `unique_consumer_group` (Boolean) Whether every application ID (the consumer group of an application) must be unique in the tenant.

## Example Usage

```hcl
data "axual_tenant" "this" {}

output "tenant_short_name" {
  value = data.axual_tenant.this.short_name
}

# Fail the plan early when Connect is switched off for the tenant.
check "connect_is_on" {
  assert {
    condition     = data.axual_tenant.this.connect_runtime_enabled != false
    error_message = "Connect is switched off for tenant ${data.axual_tenant.this.short_name}. Set connect_runtime_enabled in axual_tenant_settings."
  }
}
```
